10 KB time was total 0.130s
1 MB time was total 0.128s
10 MB time was total 0.145s
50 MB time was total 0.345s
100 MB time was total 0.553
500 MB time was total 2.675

The main bottleneck seems to come from the fact that for every request that the 
program makes, the program has to first request, wait for the server to reply, and 
read and transfer the chunk before moving onto the next request, therefore the bigger
the file, with a chunk size of 5000 bytes, the program will have to run longer to 
recieve all those pieces. The 100 MB file for example took 0.553 seconds, whereas the 500MB 
file took 2.675 seconds. In other words, larger files need more transfers, and more transfers
end up taking more time.
